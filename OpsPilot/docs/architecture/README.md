## 📐 图表说明

本文档使用 **Mermaid** 语法绘制图表，支持：
- 架构图 (graph)
- 时序图 (sequenceDiagram)
- 流程图 (flowchart)
- 状态图 (stateDiagram)

在 GitHub、VS Code（安装 Mermaid 插件）等环境中可直接渲染。
