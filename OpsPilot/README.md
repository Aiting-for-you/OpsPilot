# OpsPilot: 企业级运维智能领航系统

## 一句话介绍

基于 **LangChain + AgentScope** 的企业级大模型应用，以工具调用为核心，实现可迁移的 Agent 开发方法论。

---

## 核心价值

| 价值点 | 说明 |
|--------|------|
| **工具调用为核心** | 基于 MCP 协议实现大模型与企业系统的连接 |
| **多智能体协作** | 解决单智能体工具过载、决策复杂的问题 |
| **可迁移方法论** | 四步落地法，可快速迁移到其他垂直场景 |

## 设计哲学

### 为什么需要多智能体？

在企业级场景中，单智能体面临以下挑战：

| 问题 | 表现 | 影响 |
|------|------|------|
| 工具过载 | 单 Agent 管理 20+ 工具 | 选择准确率下降 |
| 上下文拥挤 | 工具描述 + 知识库 + 记忆 | 关键信息被稀释 |
| 决策复杂 | 业务规则 + 合规要求 | 容易决策失误 |
| 单点故障 | 一处出错全局失败 | 系统脆弱 |

### 双框架分层协作

```
┌─────────────────────────────────────────────────────────────┐
│                  AgentScope (调度大脑)                       │
│                                                             │
│   多 Agent 编排 │ 消息协调 │ 状态管理 │ 博弈仲裁             │
│                                                             │
└─────────────────────────┬───────────────────────────────────┘
                          │ 调用
                          ▼
┌─────────────────────────────────────────────────────────────┐
│                  LangChain (脚手架/执行层)                   │
│                                                             │
│   MCP 工具封装 │ RAG 检索 │ 记忆管理 │ 确定性逻辑            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**LangChain 的角色**：利用成熟生态，负责 RAG、工具封装、记忆管理等基础能力

**AgentScope 的角色**：多 Agent 协调、状态机管理、MsgHub 消息中心

## 技术栈

| 层次 | 技术 | 说明 |
|------|------|------|
| **决策层** | AgentScope | 多智能体编排与协调 |
| **执行层** | LangChain | 工具封装、RAG、记忆管理 |
| **推理引擎** | SGLang | 结构化输出、Prefix Caching |
| **微调框架** | LLaMA-Factory | 领域适配、工具调用对齐 |
| **工具协议** | MCP (Model Context Protocol) | 标准化工具接口 |
| **向量存储** | ChromaDB | 知识库存储 |
| **会话存储** | Redis | 短期记忆 |

## 核心模块概览

### 1. 工具调用 (MCP)

本项目以**工具调用为核心**，通过 MCP 协议连接大模型与企业系统：

```
用户意图 → 工具选择 → 参数提取 → 工具执行 → 结果处理
              ↓
         [失败] → 重试 → 降级 GUI → 人工介入
```

### 2. 多智能体协作

```
Orchestrator (编排)
    ├── BuyerAgent (采购)
    ├── FinanceAgent (财务)
    ├── ComplianceAgent (合规)
    └── ExecutorAgent (执行)
```

### 3. 知识库体系

| 类型 | 内容 | 用途 |
|------|------|------|
| 政策知识库 | 海关政策、平台规则 | 合规校验 |
| 业务知识库 | 商品、供应商、价格 | 业务决策 |
| 案例知识库 | 成功/失败案例 | 经验复用 |

### 4. 记忆系统

```
短期记忆 (Redis)          长期记忆 (ChromaDB)
├── 会话状态               ├── 成功案例
├── 执行轨迹               ├── 失败案例
└── 临时上下文             └── 业务知识
```

## 演示场景

### 场景：采购审批自动化

```
用户输入："紧急采购 1000 套电子元件 A"

执行流程：
1. Orchestrator 解析意图 → 拆解任务
2. BuyerAgent 查询供应商 → MCP 工具调用
3. FinanceAgent 预算审核 → 多 Agent 博弈
4. ComplianceAgent 合规校验 → RAG 检索政策
5. ExecutorAgent 创建订单 → ERP 集成

输出：订单创建成功，订单号 #2024-001234
```
